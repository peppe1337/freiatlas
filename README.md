# Freiatlas

Alle Orte, an denen dein Vermögen reicht. Eine Weltkarte für finanzielle Unabhängigkeit: Du trägst Haushalt und Vermögen ein, die Karte zeigt nach einem offengelegten Modell, wo es ohne Arbeit reicht, wo mit 20 oder 40 Stunden pro Woche, und wo noch nicht.

Dieses Repository enthält die veröffentlichte statische Website (Landing Page, App unter `app/`, Rechtsseiten). Alles wird im Browser gerechnet, ohne Konto, ohne Cookies, ohne Tracking.

Datenquellen und Lizenzen der verwendeten Software und Daten stehen in `LICENSES.txt`. Preisniveaus je Land: Weltbank ICP 2021 und World Development Indicators (CC BY 4.0). Freiatlas ist eine Beta und keine Anlage-, Steuer- oder Rechtsberatung.
